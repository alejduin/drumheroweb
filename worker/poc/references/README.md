# Referencias para medir la precisión (Fase A)

Una referencia por canción, con el mismo id que el audio en `../songs/`.
**Nada de esta carpeta se sube al repo** (solo este README).

- Si tienes MIDI de la batería: `01-rock-simple.mid`
- Si tienes Guitar Pro: `01-rock-simple.gp5` (o `.gp`, `.gpx`)
- Si no tienes ninguno, se graba tocando con la TD-02KV (herramienta A4) y se guarda aquí como `01-rock-simple.json`.
