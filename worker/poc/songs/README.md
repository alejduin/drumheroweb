# Canciones para la prueba de concepto (Fase A)

Deja aquí tus archivos de audio. **Nada de esta carpeta se sube al repo** (solo este README).

- Formato: MP3, WAV o M4A, de 2 a 5 minutos.
- Cinco canciones de estilos variados:
  1. rock o pop sencillo, con la batería bien audible
  2. mucho hi-hat (corcheas o semicorcheas)
  3. fills de toms
  4. mezcla densa (guitarras distorsionadas, mucha voz)
  5. tempo rápido
- Nombre de archivo sin espacios ni acentos, por ejemplo `01-rock-simple.mp3`.
  Ese nombre (sin extensión) es el id de la canción en todo el PoC.
